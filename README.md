 ¿De qué trata este proyecto?
Tienda Deportiva es un sitio web que simula una tienda de artículos deportivos, pensada especialmente para jóvenes y con un gran enfoque en el fútbol.

Mi objetivo era crear una experiencia moderna y que se viera bien. Por eso elegí una paleta de colores morados oscuros con toques dorados, para darle un aire elegante pero con energía juvenil.

El sitio tiene varias secciones (Inicio, Catálogo y Contacto) y está hecho 100% con HTML, CSS y JavaScript.

 Objetivos
Quería lograr varias cosas con este proyecto:

1.Diseñar un sitio que se viera bien, fuera funcional y se adaptara a celulares (responsivo).
2.Mostrar un catálogo de productos dinámico, cargando la información desde un archivo JSON.
3.Hacer que el formulario de contacto funcionara y mostrara un pop-up de confirmación al enviarlo.
4.Aplicar buenas prácticas de HTML semántico y accesibilidad básica.

 Estructura de Archivos
Para este proyecto, mantuve la estructura simple, con los archivos principales en la raíz esto debido a que en Github no se puede extraer carpetas.

 ¿Qué hay en cada sección?
 Inicio: La página de bienvenida. Aquí presento la tienda, sus valores y algunos productos destacados.
 Catálogo: Esta es la sección central. Aquí se cargan todos los productos desde el productos.json. Incluye funciones para filtrar por nombre y ordenar (por precio o alfabéticamente).
 Árbol: Esta sección (que también aparece en el catálogo) muestra las categorías (Fútbol, Basket, etc.). Puedes hacer clic en cada una para ver los productos que contiene.
 Contacto: La página de "Acerca de" y el formulario. Cuando envías el formulario, aparece un pop-up confirmando que se recibió.
